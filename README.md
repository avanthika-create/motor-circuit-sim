This project is a reaction time simulator that models how changes in dopamine levels can affect motor response timing, inspired by the role dopamine plays in motor circuit and movement. This project began as a Python reaction time experiment and was later converted into an interactive web using HTML, CSS, and JavaScript. Users will complete a series of reaction time trials after a visual stimulus appears.
